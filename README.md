# SISTEMA_DE_SEMAFOROS_FRONTEND
Es un prototipo educativo para controlar dos semáforos con LEDs mediante una maqueta IoT:  React muestra una interfaz web. FastAPI procesa el estado y controla los modos manual o automático. ESP32 recibe comandos y usa sensores HC-SR04 para detectar vehículos. Permite priorizar una vía o alternar el ciclo automáticamente.
